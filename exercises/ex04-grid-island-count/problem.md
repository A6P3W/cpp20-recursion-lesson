# 演習4: 島の個数カウントと最大面積（グリッドDFS）

## 問題文

縦 $H$ 行、横 $W$ 列のグリッドで表される地図があります。
上から $i$ 行目、左から $j$ 列目のマスは文字 $C_{i, j}$ で表され、`#` は**陸地**、`.` は**海**を意味します。

上下左右に隣接する陸地マス同士はつながっており、つながっている陸地マスの塊（連結成分）を **「島」** と呼びます（※斜めに隣接しているだけの陸地はつながっているとは見なしません）。

地図の中に**島がいくつあるか**、また**最も大きい島に含まれる陸地マスの数（最大面積）**はいくつかを求めてください。
なお、島が1つも存在しない場合の最大面積は `0` とします。

---

## 制約

- $1 \le H, W \le 500$
- $C_{i, j}$ は `#` または `.`
- $H, W$ は整数

---

## 入力形式

標準入力から以下の形式で与えられます。

```text
H W
C_{1,1}C_{1,2}...C_{1,W}
...
C_{H,1}C_{H,2}...C_{H,W}
```

## 出力形式

島の個数と、最も大きい島の面積（マス数）を空白区切りで1行に出力してください。

---

## 入出力例

### 入力例 1

```text
4 5
##...
.#..#
....#
###.#
```

### 出力例 1

```text
3 3
```

以下の3つの島が存在します。

1. 左上の島：`(0,0), (0,1), (1,1)` の $3$ マス
2. 右側の島：`(1,4), (2,4), (3,4)` の $3$ マス
3. 左下の島：`(3,0), (3,1), (3,2)` の $3$ マス

島の個数は `3`、最大面積は `3` です（`(1,1)` と `(3,0)` などは離れており、斜め隣接も別の島となります）。

### 入力例 2

```text
3 3
...
...
...
```

### 出力例 2

```text
0 0
```

---

## ヒント

1. **DFSの戻り値で面積を計算する**:
   `dfs(r, c)` が「マス `(r, c)` から到達できる未訪問の陸地マスの総数」を `int` で返すように書くと、島の面積も同時に求まります。
   - 最初に `int area = 1;`（自分自身の1マス分）とする。
   - 4方向の未訪問の陸地 `(nr, nc)` に対して `area += dfs(nr, nc);` で足し合わせる。
   - 最後に `return area;` を返す。
2. **全マスを走査する2重ループ**:
   `grid[r][c] == '#'` かつ `!visited[r][c]` のマスを見つけたら、島の個数を `+1` し、`dfs(r, c)` を呼んで返ってきた面積で最大値を更新（`std::max`）します。
