## 問題文

$N$ 個の正の整数 $A_1, A_2, \dots, A_N$ と、目標の合計値 $S$ が与えられます。

$N$ 個の整数の中からいくつか（$0$ 個以上 $N$ 個以下）を選んで、**選んだ整数の合計がちょうど $S$ になる選び方が何通りあるか**を求め、さらに**条件を満たす選び方（選んだ要素の列）をすべて出力**してください。

ただし、選び方を出力する順序は以下のルールに従ってください。

- 各要素 $A_1, A_2, \dots, A_N$ について、まず「$A_i$ を**選ぶ**」分岐を先に探索し、次に「$A_i$ を**選ばない**」分岐を探索したときに発見される順番で出力する。

---

## 制約

- $1 \le N \le 20$
- $1 \le S \le 10^9$
- $1 \le A_i \le 10^9$
- 入力はすべて整数

---

## 入力形式

標準入力から以下の形式で与えられます。

```text
N S
A_1 A_2 ... A_N
```

## 出力形式

1行目に、合計がちょうど $S$ になる選び方の総数 $K$ を出力してください。
続く $K$ 行に、それぞれの選び方で選んだ整数を（元の配列の順番のまま）空白区切りで出力してください。

---

## 入出力例

### 入力例 1

```text
4 10
3 5 2 8
```

### 出力例 1

```text
2
3 5 2
2 8
```

- $(A_1, A_2, A_3) = (3, 5, 2)$ を選ぶと $3 + 5 + 2 = 10$ になります。
- $(A_3, A_4) = (2, 8)$ を選ぶと $2 + 8 = 10$ になります。
- 合計が $10$ になるのはこの $2$ 通りです。

### 入力例 2

```text
3 100
10 20 30
```

### 出力例 2

```text
0
```

すべて足しても $60$ なので、合計を $100$ にする方法は $0$ 通りです。

---

## ヒント

1. **バックトラッキング用の配列**:
   現在選んでいる要素を入れておく `std::vector<long long> chosen` と、見つかった正解リストを保存する `std::vector<std::vector<long long>> answers` を用意します。
2. **枝刈り（Pruning）**:
   入力される $A_i$ はすべて正の整数（$A_i \ge 1$）なので、途中で `current_sum > S` になったら、それ以上要素を足しても絶対に $S$ にはなりません。即座に `return` して探索を打ち切りましょう。
3. **選ぶ → 戻す → 選ばない**:
   ```cpp
   // 1. A[index] を選ぶルート
   chosen.push_back(A[index]);
   self(self, index + 1, current_sum + A[index]);
   chosen.pop_back(); // 必ず元に戻す！

   // 2. A[index] を選ばないルート
   self(self, index + 1, current_sum);
   ```
