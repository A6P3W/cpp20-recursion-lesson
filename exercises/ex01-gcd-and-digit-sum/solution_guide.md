## 1. 解法の着眼点・アプローチ

この問題では、数値の桁を分解する再帰と、2数の余りを使って規模を縮小するユークリッドの互除法の2つの基本再帰を実装します。

### 桁和 `digit_sum(n)` の構造

10進数の整数 $n$ に対して、

- `n % 10` で**一番右の桁（一の位）**を取り出せます。
- `n / 10` で**一番右の桁を切り落とした残りの数**を作れます。

$n \le 10^{18}$ のとき桁数は最大19桁なので、再帰の深さも高々19回で終了します（計算量 $O(\log_{10} N)$）。

### ユークリッドの互除法 `my_gcd(x, y)` の構造

「$x$ を $y$ で割った余りを $r = x \bmod y$ とすると、$\gcd(x, y) = \gcd(y, r)$ が成り立つ」という数学的性質をそのまま再帰関数に落とし込みます。
1回の再帰ごとに数値が急速に小さくなり、計算量は $O(\log(\min(x, y)))$ です。

## 2. コードのステップ解説

```cpp
auto digit_sum = [](auto& self, long long n) -> long long {
    if (n < 10) {
        return n;
    }
    return (n % 10) + self(self, n / 10);
};
```

- C++20のジェネリックラムダ再帰構文（`auto& self`）を使っています。
- ベースケース `if (n < 10) return n;` は `n == 0` としても正しく動きますが、`n < 10` で止めると1回分早く返ることができます。

```cpp
auto my_gcd = [](auto& self, long long x, long long y) -> long long {
    if (y == 0) {
        return x;
    }
    return self(self, y, x % y);
};
```

- もし最初に $x < y$（例: `my_gcd(15, 30)`）で呼ばれたとしても、1回目の再帰で `15 % 30 = 15` となり、次は `my_gcd(30, 15)` と自動的に大小が入れ替わるため、事前に `swap(x, y)` をする必要はありません。

---

## 3. よくある間違い・注意点 (Gotchas)

1. **`int` 型を使ってオーバーフローする**:
   制約が $A, B \le 10^{18}$ なので、`int`（最大約 $2 \times 10^9$）では入力を受け取る時点でオーバーフローします。必ず `long long` を使いましょう。
2. **ラムダ再帰で戻り値の型 `-> long long` を書き忘れる**:
   `auto digit_sum = [](auto& self, long long n) { ... }` のように戻り値型推論に任せると、再帰呼び出し部分で型が推論できない場合があるため、再帰ラムダでは常に `-> 型名` を明記する癖をつけましょう。
