# 演習5: 木の部分木サイズと深さのクエリ（木DFS）

## 問題文

頂点に $1$ から $N$ までの番号がついた $N$ 頂点の**根付き木**があります。根（Root）は**頂点 $1$** です。
$i$ 番目 ($1 \le i \le N - 1$) の辺は頂点 $U_i$ と頂点 $V_i$ を双方向に結んでいます。

$Q$ 個のクエリが与えられます。$j$ 番目 ($1 \le j \le Q$) のクエリでは頂点番号 $X_j$ が与えられるので、以下の2つの値を空白区切りで出力してください。

1. **頂点 $X_j$ の深さ**：根（頂点 $1$）から頂点 $X_j$ までの最短パスに含まれる辺の本数（頂点 $1$ 自身の深さは $0$）。
2. **頂点 $X_j$ の部分木サイズ**：頂点 $X_j$ を根とする部分木に含まれる頂点の総数（頂点 $X_j$ 自身も含む）。

---

## 制約

- $1 \le N \le 2 \times 10^5$
- $1 \le Q \le 2 \times 10^5$
- $1 \le U_i, V_i \le N$ ($U_i \neq V_i$)
- 与えられるグラフは木であることが保証される
- $1 \le X_j \le N$
- 入力はすべて整数

---

## 入力形式

標準入力から以下の形式で与えられます。

```text
N Q
U_1 V_1
U_2 V_2
...
U_{N-1} V_{N-1}
X_1
X_2
...
X_Q
```

## 出力形式

$Q$ 行出力してください。$j$ 行目には $j$ 番目のクエリ $(X_j)$ に対する「深さ」と「部分木サイズ」を空白区切りで出力してください。

---

## 入出力例

### 入力例 1

```text
6 4
1 2
1 3
2 4
2 5
3 6
1
2
3
5
```

### 出力例 1

```text
0 6
1 3
1 2
2 1
```

木の構造は以下の通りです。

```text
        1 (depth=0, size=6)
       / \
      2   3 (depth=1, size=2)
     / \   \
    4   5   6
```

- 頂点 $1$: 深さ $0$、部分木は $\{1, 2, 3, 4, 5, 6\}$ の $6$ 個
- 頂点 $2$: 深さ $1$、部分木は $\{2, 4, 5\}$ の $3$ 個
- 頂点 $3$: 深さ $1$、部分木は $\{3, 6\}$ の $2$ 個
- 頂点 $5$: 深さ $2$、部分木は $\{5\}$ の $1$ 個

---

## ヒント

1. **クエリごとにDFSをしてはいけない！**:
   $N, Q \le 2 \times 10^5$ なので、クエリが来るたびにDFSを行うと $O(NQ)$（最大 $4 \times 10^{10}$ 回の計算）となり確実に TLE します。
2. **前計算 $O(N)$ + クエリ応答 $O(1)$**:
   クエリに答える前に、**頂点 $1$ からたった1回だけ木DFSを実行**し、すべての頂点 $u$ について `depth[u]` と `subtree_size[u]` を配列に求めておきます。すると、各クエリには配列の値を参照するだけで $O(1)$ で答えられます。
3. **1-indexed（1始まり）の扱い**:
   配列サイズを `n + 1`（`0` 〜 `n`）で確保しておけば、入力の頂点番号 $1 \sim N$ を `-1` せずにそのまま添字として使えてバグが減ります。
